# Stacks and Queues

This repository contains stack and queue implementations using arrays and linked lists for the Unit IV practical activity.

## Implementations

1. Stack using an array
2. Queue using an array
3. Stack using a linked list
4. Queue using a linked list

## Operations

- **Stack:** Push, Pop, Peek, and Display (LIFO: Last In, First Out)
- **Queue:** Enqueue, Dequeue, Front, and Display (FIFO: First In, First Out)

The programs demonstrate basic data structure operations and handling of conditions such as removing an item from an empty structure.

## How to Run

Compile and run each program using the compiler for the language used in this repository.

For C++:

```bash
g++ filename.cpp -o program
./program
